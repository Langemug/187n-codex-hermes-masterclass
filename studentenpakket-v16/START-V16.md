# Start met LIO

1. Download de complete cursus via GitHub en pak het ZIP-bestand uit.
2. Open de uitgepakte cursusmap als project in Codex Desktop. Je kunt ook alleen `studentenpakket-v16` openen.
3. Typ **Start de masterclass**.

LIO vraagt naar jouw product of dienst en helpt je stap voor stap bouwen. Je hebt voor de cursuscoach geen terminalcommando nodig. De gebruikte modellen en verbonden tools werken met je eigen accounts.

## Kijk je al mee met een video?

Typ het nummer van die video, bijvoorbeeld **Start les 54**. De bestaande code werkt ook: **Start les N28** opent dezelfde les.

- **Toon alle lessen** opent het overzicht van 113 lessen.
- **Ga verder** hervat je opgeslagen stap, ook in een nieuw gesprek in hetzelfde project.
- **Leg dit eenvoudiger uit** geeft meer uitleg bij de huidige stap.
- **Volgende les** gaat naar het volgende nummer. Openstaand werk blijft bewaard.

Je kunt [alle lessen bekijken](interactief/LESSEN.md) of de [bestaande werkkaarten](WERKKAARTEN.md) gebruiken. LIO bewaart resultaten onder `outputs/` en voortgang lokaal in `.lio/`. Laat die mappen staan wanneer je later verdergaat.

## Mac en Windows

Installeer Codex Desktop via de officiële OpenAI-download en meld je aan. Pak op Windows het ZIP-bestand eerst volledig uit met **Alles uitpakken**; open geen map vanuit het ZIP-venster. Open op Mac de uitgepakte map als project. Je hoeft geen verborgen map zichtbaar te maken of bestanden naar een globale skillsmap te kopiëren.

Als het skillmenu LIO nog niet toont, werkt **Start de masterclass** via de projectinstructies. Kan Codex de lesindex niet lezen, controleer dan of de volledige cursusmap is geopend. Bij een onvolledige download pak je de release opnieuw uit in een nieuwe map.

Hermes en andere tools komen aan bod wanneer je ze nodig hebt. LIO controleert de beschikbare versie en helpt de passende setup volgen. Aanmelden doe je zelf; plak nooit geheime sleutels in het gesprek.
