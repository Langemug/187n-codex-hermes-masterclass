## Kernregels uit de bron (letterlijk samengevat, met sectie)
| # | Regel | Sectie |
|---|---|---|
| R1 | Zoekwoorden in natuurlijke, leesbare zinnen; geen losse keyword-lijsten | Note / Meta description |
| R2 | Vier plekken: page title, meta description, ALT tags, body content (+ H1 via Title-veld) | intro / H1 |
| R3 | Title: uniek, beschrijvend, belangrijkste zoekwoord vooraan, ≤ 60 tekens (veld max 70) | Page title |
| R4 | Title-tips: primair + secundair zoekwoord, unieke producteigenschap, voordeel met eerlijke beperking | Tips title tags |
| R5 | Meta description: uniek per pagina, eenvoudige taal, ~160 tekens, relevante zoekwoorden | Meta description |
| R6 | Alt text: beschrijf wat er te zien is, met zoekwoorden van de pagina; Products > image > Edit alt text | Set image alt text |
| R7 | H1 = Title-veld van product; zet hoofdzoekwoord erin | H1 |
| R8 | Body: unieke tekst, geen fabrikanttekst kopiëren; product ≥ 250 woorden, blog ≥ 500 woorden | Page content |
| R9 | Controle: View Page Source → <title> en <meta name="description"> moeten overeenkomen met admin | Troubleshooting |
| R10 | Google kan title/description herschrijven; herindexering duurt dagen–weken (URL Inspection) | Troubleshooting / Common questions |
